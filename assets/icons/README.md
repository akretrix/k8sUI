# Icon Provenance and Licensing

This directory contains icon assets used across the k9sUI desktop interface.

---

## 1. Icon Categories

### Generic UI Icons (Tabler Icons)
- **Source**: [Tabler Icons](https://github.com/tabler/tabler-icons)
- **License**: MIT License (Copyright (c) 2020-2026 Paweł Kuna)
- **Usage**: Used for standard desktop chrome (close, search, terminal, settings, lock, chevron, refresh, filter).

### Custom Kubernetes Resource Kind SVGs (`assets/icons/src/`)
- **Source**: Custom vector icons designed for k9sUI.
- **License**: Apache License, Version 2.0 (Copyright 2026 k9sUI Authors).
- **Contents**:
  - `pod.svg` - Kubernetes Pod resource
  - `deployment.svg` - Kubernetes Deployment resource
  - `service.svg` - Kubernetes Service resource
  - `configmap.svg` - Kubernetes ConfigMap resource
  - `secret.svg` - Kubernetes Secret resource (with lock motif)
  - `ingress.svg` - Kubernetes Ingress resource
  - `node.svg` - Kubernetes Cluster Node resource
  - `namespace.svg` - Kubernetes Namespace resource
